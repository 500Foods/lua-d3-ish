# lua-d3-ish

This repository contains a port of D3.js that works in Lua without linking to external libraries. Not awrapper. But it only ports the non-interactive bits. Basically a way to draw charts the same way D3.js does, outputting SVGs like D3.js does, and using D3.js output as the oracle to validate against.
